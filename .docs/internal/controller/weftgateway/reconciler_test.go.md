## TL;DR
This file contains integration tests for the `WeftGatewayReconciler`, verifying that Gateway resources are correctly translated into WeftTunnel and DNSRecord objects.

The test suite validates URL scheme construction based on listener protocols: `http://` for HTTP, `https://` for HTTPS/TLS passthrough, `tcp://` for TCP, and `udp://` for UDP. It ensures that L7 routes (HTTP/HTTPS/TLS) fan out to all eligible bastions, while L4 routes (TCP/UDP) pin to a single bastion to avoid port collisions. A critical regression test confirms that routes are attached only to their specific listeners via `sectionName`, preventing cross-product tunnel creation. The tests use `fakeclient` to bypass CRD validation where necessary, focusing on reconciliation logic rather than API server constraints.
