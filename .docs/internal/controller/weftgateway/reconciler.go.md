## TL;DR
This file implements the `WeftGatewayReconciler` that translates Gateway API resources into WeftTunnels and DNSRecords.

The reconciler watches `Gateway`, `HTTPRoute`, `TCPRoute`, `TLSRoute`, `UDPRoute`, and `AquaductTaaS` objects. It filters routes by matching them to specific listeners (respecting section names and hostnames) and creates corresponding `WeftTunnel` CRs for each backend service. For L4 protocols (TCP/UDP), it pins traffic to a single eligible bastion; for L7, it fans out to all non-suspended bastions. It also automatically generates `DNSRecord` CRs for listener hostnames and cleans up stale tunnels and records during Gateway deletion via a finalizer. HTTP header modifiers are translated into URL fragments on tunnel source URLs.
