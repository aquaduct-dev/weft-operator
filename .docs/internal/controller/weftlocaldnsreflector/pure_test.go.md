## TL;DR
This file contains unit tests for the pure helper functions that derive routes from WeftTunnels and render CoreDNS configuration blocks.

It validates `computeRoutes` logic, ensuring correct priority resolution when multiple tunnels target the same destination, proper handling of matcher fragments (e.g., headers), and filtering of invalid or unrequested hosts. It verifies `renderCoreDNS` produces syntactically valid CoreDNS zones with balanced braces, sorted blocks, and correct input validation for IPs and hostnames. Finally, it tests `resolveClaims` to confirm that explicit hostname claims take precedence over `allHostnames` modes, that deleting reflectors are ignored, and that conflicting claims are correctly identified among multiple reflectors.
