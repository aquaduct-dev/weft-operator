## TL;DR
This file contains unit tests for the trust webhook handler and its setup logic, verifying injection behavior, certificate management, and edge cases like dry runs and cache lag.

The test suite validates `Handler.Handle` to ensure pods are patched with CA bundles while respecting dry-run constraints (no ConfigMap creation) and opt-out labels. It confirms that foreign ConfigMaps are left untouched and that injection proceeds even if the local cache lags behind the operator's own bundle publication. The `TestSetup` function verifies the creation of the `MutatingWebhookConfiguration`, ensuring correct namespace exclusions and DNS paths. It also checks that serving certificates are persisted correctly across restarts without rotation unless inside the renewal window, guaranteeing stable CA identity for the API server.
