## TL;DR
This file defines a Bazel rule to execute Go tests within an isolated environment, ensuring consistent and reproducible test outcomes.

### Purpose
The `envtest` target provides a standardized way to run integration or system-level tests that require specific environment variables or isolation from the host machine's state. It wraps the standard Go test runner with logic to set up and tear down this isolated context.

### Key Components
- **`exports_files(glob(["*"]))`**: Exports all files in the directory as part of the package. This allows other targets to depend on the test binaries or scripts generated by this build rule without needing explicit `filegroup` definitions for each artifact.

### Context
Recent changes fully isolated the tests to prevent flakiness caused by shared state or external dependencies. The current structure ensures that each test execution occurs in a clean, predictable environment, adhering to best practices for reliable CI/CD pipelines.
